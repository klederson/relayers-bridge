# Upstream attribution

RELAYERS Bridge derives its conversation-link routing, quick-reply UI, saved replies, optional OpenRouter integration, media placeholders, silent badge and related tests from [TabHero](https://github.com/klederson/tabhero), by Klederson Bueno, under the MIT license.

Initial source snapshot: `4aa59beb44e4e8a5ade6f0c19e861c8ff373f397`.

The MIT copyright and license are retained in [LICENSE](LICENSE). This is a separate extension with its own identifier, storage, disclosures and release lifecycle. It does not require TabHero to be installed. Integration-specific code is independently implemented here; the RELAYERS backend and its private implementation plan are not included.

The shared code is currently an attributed source snapshot. An extracted versioned core package is a future maintenance improvement, not an existing dependency.
