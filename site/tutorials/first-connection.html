FROM ZERO TO A ROUND TRIP

Connect WhatsApp to an order desk. Start a test conversation, watch the response reach the desk, reply there and check it back in WhatsApp.

You get the installation files, an application to open and a checkpoint at every stage. First complete the test on one computer; using another computer comes afterwards.

START WITH NOTHING CONFIGURED

One question. One reply. Four stages.

  1. 01Prepare your account and extension
  2. 02Open the order desk
  3. 03Connect both paths
  4. 04Receive and reply to a message

Version 0.2.0 interface

This walkthrough uses 0.2.0 installed from the project source. Download the package below and follow the installation step. Store updates have not been confirmed.

How to install the test package ↗

Before you start

  • Chrome on a computer and WhatsApp on your phone.
  • A second number you own or a participant who agreed to test.
  • A RELAYERS account, which you can create in step one.
  • The Bridge and desk packages, available in this guide.
01

STEP 1

Create your account or sign in to RELAYERS.

On the RELAYERS website

First, prepare the account you will use in both Bridge and the desk.

Sign in to RELAYERS ↗Create an account ↗
  1. Click “Create my account” below, or “Sign in to RELAYERS” if you already have one.
  2. To register, enter your name, email and a password of at least 12 characters, then click “Start Free”. If you already have an account, enter your email and password on the sign-in page and click “Sign in”.
  3. Keep that account signed in in your browser.
✓
Check before continuing

You can access your RELAYERS panel.

Did the expected result not appear?

If the site says “too many requests”, wait before trying again. Do not keep clicking sign in.

02

STEP 2

Install the version used in this walkthrough.

In Chrome

We use Chrome and this project’s 0.2.0 source package. Its interface includes the WhatsApp configuration button.

Chrome 0.2.0 ↓
  1. Download “Chrome 0.2.0” below and extract the whole archive to a folder. Keep that folder.
  2. In Chrome’s ⋮ menu, open “Extensions” → “Manage extensions”. Enable “Developer mode”.
  3. Click “Load unpacked” and choose the extracted folder containing the extension manifest. Do not choose the archive itself.
  4. Check that the “RELAYERS Bridge” card shows version 0.2.0 and is enabled. Pin Bridge in Chrome’s extensions menu.
✓
Check before continuing

The extension card shows 0.2.0 and its toggle is on.

Did the expected result not appear?

If “Configure WhatsApp” is missing, check this card and its version. These are packages for manual installation.

03

STEP 3

Connect WhatsApp and choose a test participant.

In WhatsApp Web

Use a second number you own or a person who agreed to test. Do not use “Message yourself”: this check needs a message sent from the other side.

  1. Open WhatsApp Web in the same Chrome that has Bridge installed.
  2. If a sign-in code appears, link this browser using WhatsApp on your phone.
  3. Agree which conversation you will test. Keep this tab open. Do not ask for the question yet.
✓
Check before continuing

Your conversations are visible and you know which one to authorize.

Did the expected result not appear?

Old messages are not part of this check. The participant will send a new message after both paths are ready.

04

STEP 4

Open Bridge and approve access.

In the extension and official approval page

Signing in to the website and approving the extension are separate steps. Now approve the extension.

  1. Click the RELAYERS Bridge icon, then “Configure WhatsApp”.
  2. Click “Connect to RELAYERS”. If Chrome asks for access to the RELAYERS address, accept the browser prompt.
  3. Open the RELAYERS approval button. Check the code and click “Approve device”. Sign in if asked.
  4. Return to Bridge and wait for the conversation list.
✓
Check before continuing

The official page says “Device approved” and Bridge displays conversation selection.

Did the expected result not appear?

Enter your password only on the official RELAYERS page. If the code expires, begin approval again from Bridge.

05

STEP 5

Allow only the test conversation, in both directions.

On the Bridge page

One conversation is enough for this first example.

  1. Check the selected WhatsApp tab. Search for the test participant and select only that conversation.
  2. Enable receiving “Incoming messages → RELAYERS” and sending “RELAYERS → outgoing messages”.
  3. Read and check the displayed authorization.
✓
Check before continuing

The test conversation is selected and both directions are enabled.

Did the expected result not appear?

If it is missing, check that it exists in the selected WhatsApp account. Do not switch accounts just to make a list appear.

06

STEP 6

Create the connection. Bridge prepares IN and OUT.

Still in Bridge

We start with Basic settings so filters do not get in the way of the first result.

  1. Keep both receiving and sending filters in “Basic” mode, with their words left empty.
  2. For the receiving destination, keep receipt in RELAYERS only for now. We will connect the desk next.
  3. Click “Create connection” and wait for “Connected”.
  4. Open “Integration details”. Find two addresses: IN receives from WhatsApp; OUT accepts requests to send replies.
✓
Check before continuing

The connection is “Connected”. Bridge creates two separate addresses, IN and OUT.

Did the expected result not appear?

Do not create extra addresses manually in the panel. Use the two created by this connection.

07

STEP 7

Download and open the order desk.

On the computer where you will use the desk

This guide includes a ready application to receive the question and write a reply.

Download order desk ↓Install Node.js ↗
  1. Download the “Order desk” below and extract the entire folder.
  2. Install Node.js 22 or newer from its official website if needed. It is the program required to open this example.
  3. Open your system’s launcher: “Open-Windows.cmd”, “Open-macOS.command” or “Open-Linux.sh”. On Linux, choose to run the file.
  4. The desk opens in your browser. Keep the program window open throughout the test.
✓
Check before continuing

The “Order desk” page shows account connection and receiving/replying setup.

Did the expected result not appear?

If the browser does not open automatically, use http://127.0.0.1:47831 on that computer. If your system blocks the launcher, see the execution option in the package README.

08

STEP 8

Approve the desk with the same RELAYERS account.

In the desk and approval page

Bridge connects WhatsApp; the desk is the other participant. It also needs your approval.

  1. In the desk, click “Connect my RELAYERS account”.
  2. Click “Open approval in RELAYERS”. Use the same account as Bridge, check the code and click “Approve device”.
  3. Return to the desk and wait for “Desk connected to RELAYERS”.
  4. In block 01, check this desk’s own name in RELAYERS. Then click “Copy” beside the receiving address.
✓
Check before continuing

The desk shows a connected account and provides its receiving address.

Bridge and the desk are separate devices in your RELAYERS account. Choose the name shown by the desk to forward messages to the right computer.
Did the expected result not appear?

Do not copy your password or a login-page address. Copy the receiving address supplied by the desk itself.

09

STEP 9

Tell Bridge where the desk is.

In Bridge

Now connect incoming messages to the application you opened.

  1. Click “Configure webhooks and filters”.
  2. Under “Where should received messages go?”, choose “An application on a linked computer”. Paste the desk receiving address.
  3. Click “Find linked computers” if needed. Choose the device with the exact name displayed in desk block 01.
  4. Confirm the change authorization and click “Save WhatsApp configuration”. The connection pauses. Click “Resume” to connect again.
✓
Check before continuing

Bridge returns to “Connected” and its summary confirms forwarding to the selected computer.

Did the expected result not appear?

If the desk is missing, confirm it is running and approved under the same RELAYERS account. Refresh the list. Each desk has its own name; select the one you opened.

10

STEP 10

Copy three values from Bridge to the desk.

Between Bridge’s “Integration details” and desk block 02

This connects the desk’s receiving path and its ability to request a reply.

  1. In Bridge, open “Integration details”. Copy IN into the desk “IN address” field.
  2. Copy OUT into the desk “OUT address” field.
  3. Show the OUT sending key in Bridge. Copy the full key into the desk “OUT sending key” field. Share it only with applications you authorize to send.
  4. Click “Connect both paths” in the desk.
✓
Check before continuing

The desk shows “Desk connected to RELAYERS” and “IN and OUT connected”.

Did the expected result not appear?

Both addresses must belong to the same Bridge connection. If you see a connection error, copy all three fields again from that connection.

11

STEP 11

Start the conversation and watch the reply arrive.

On the participant’s phone and in the desk

Start a short conversation and watch the reply reach the application.

  1. In WhatsApp, send your test bot or participant: “Hello! This is an authorized RELAYERS Bridge test. Could you reply with a short message?”.
  2. Wait for the other side to answer. The illustrated test used a bot that replied “OK.”.
  3. Return to the desk and check “Received messages”. Do not copy or paste the conversation.
✓
Check before continuing

The other side’s reply appears as “Received from WhatsApp”. IN worked.

Did the expected result not appear?

If it is missing, check the authorized conversation, that the message was sent after connecting, Bridge’s Connected state, the desk connection, destination and filters. Ask for a new message after correcting the cause.

12

STEP 12

Write the reply in the desk and send.

In the desk

Reply from the application without typing it in the WhatsApp tab.

  1. Under the received message, write in “Your reply”: “Your order is ready for pickup. Thank you for contacting us!”.
  2. Click “Send reply through WhatsApp” once.
  3. Watch the status below the reply: RELAYERS first receives the request; the desk then shows the result reported by Bridge.
✓
Check before continuing

The desk reports Bridge accepted the send. OUT was used.

Did the expected result not appear?

If the result is unconfirmed, check the WhatsApp conversation before attempting another reply. Do not repeat the click to force it.

13

STEP 13

Check the reply back in WhatsApp.

In the WhatsApp test conversation

The last check happens in the actual conversation.

  1. Open the authorized conversation and find the reply you wrote in the desk.
  2. Ask a participant to confirm receipt. If testing with a bot, also watch for its next reply.
  3. Return to the desk: the received question and your reply remain visible while the program is running.
✓
Check before continuing

You saw the question reach the desk and the reply appear in WhatsApp. Both directions are connected.

Did the expected result not appear?

Accepted sending does not confirm reading. Use the conversation’s own indicators to follow delivery and reading.

14

STEP 14

End the test or keep the connection available.

In Bridge and the desk

You have a first connected path and know what needs to stay available.

  1. To continue testing, keep the WhatsApp computer on, its WhatsApp session connected, Bridge active and the desk running.
  2. To finish, pause Bridge and click “Disconnect and clear local data” in the desk.
  3. Follow the filters guide after completing this first round trip.
✓
Check before continuing

You know how to keep the connection available and stop it.

Did the expected result not appear?

The desk is a demonstration. Closing the program clears its history and credentials. An everyday support application must manage its own history and team access.

A CONVERSATION IN BOTH DIRECTIONS

Two paths. A clear purpose for each.

RECEIVE · IN

Someone writes in WhatsApp. Bridge brings the new message to RELAYERS. RELAYERS forwards it to the application you chose.

SEND · OUT

The application requests a reply. RELAYERS passes that request to Bridge. The linked WhatsApp sends to the authorized conversation.

Receiving and sending are separate actions. An incoming message can reach your application; a reply depends on an action or a rule you set up there.

THE LOCATION IS YOUR CHOICE

Here at your business or somewhere else?

◉RELAYERS→Your local application

In this walkthrough the desk and WhatsApp run on the same computer. The desk includes its own RELAYERS connection. Select its device in Bridge and use its displayed receiving address.

Download the order desk ↗
◎RELAYERS→Application elsewhere

To use the desk on another computer, open the same package there and approve it under the same RELAYERS account. In the Bridge that stays with WhatsApp, select that desk device and its displayed address. Write the reply on the other computer while the WhatsApp computer stays available. This is an optional variation after the first test.

Already have an online system?

If your existing system provides an online receiving address, choose “An application available online” in Bridge and paste that address. For the desk running on another computer, keep “An application on a linked computer” and choose that desk’s name. That desk is also a RELAYERS device; an application receiving through a public address does not need to register a computer.

The first round trip above uses the desk on the same computer. Change its location after confirming that result.
